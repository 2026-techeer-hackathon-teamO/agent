# agent — Windows 기밀 유출 방지 백그라운드 에이전트

사내(인가된 관리 대상) Windows PC에서 백그라운드로 동작하며, **기밀 데이터의 외부 유출을 탐지·차단**하고 관련 로그를 수집해 서버로 전송하는 방어 보안(DLP) 에이전트입니다.

> ⚠️ 이 에이전트는 **조직이 소유·관리하는 기기에, 사용자(직원) 고지 및 조직 정책 하에 배포**되는 것을 전제로 합니다. 동의 없는 개인 기기 감시 용도가 아닙니다.

## 역할 (설계 범위)

| 기능 | 설명 |
|---|---|
| 메일 유출 차단 | 기밀로 분류된 파일이 메일 첨부로 나가는 것을 탐지/차단 |
| USB 유출 차단 | 기밀 파일이 USB 등 이동식 저장소로 복사되는 것을 탐지/차단 |
| 로그 수집·전송 | 파일 접근/복사/전송 이벤트를 수집해 `backend`로 전송 |
| 디코이(허니팟) 배치 | `backend`가 생성한 유사 기밀 파일(카나리토큰 포함)을 PC에 배치 |

AI 해킹 패턴 판단, 담당자 알림(Slack), 카나리토큰 수신은 **`backend`** 레포에서 처리합니다.

## 연동

- 로그 전송 대상: `backend` 의 `POST /api/logs`
- 디코이 파일 배치: `backend` 의 `GET /api/decoys` 에서 내려받아 지정 경로에 배치
